# Кусты и деревья для карты

Шесть отдельных PNG с альфа-каналом, вид строго сверху, в стиле референса
карты с Монолитом. Встроенный генератор изображений; промпты — в generation.json.

| Файл | Вариант | Начальная видимая ширина, игровые единицы |
| --- | --- | --- |
| bush-01-compact.png | Плотный компактный куст | 18 |
| bush-02-spreading.png | Раскидистый куст с просветами | 26 |
| bush-03-dry.png | Редкий суховатый куст | 22 |
| tree-01-round.png | Дерево с широкой округлой кроной | 64 |
| tree-02-airy.png | Лиственное дерево с вытянутой кроной | 56 |
| tree-03-conifer.png | Хвойное дерево с лучистой кроной | 52 |

Размеры — стартовые ориентиры при диаметре наземного юнита около 20 единиц,
не проверенные в игре. Речь о ширине видимого растения, без прозрачных полей.
Сохраняйте пропорции изображения: второй куст имеет холст 1536×1024,
остальные — 1254×1254. Не растягивайте все PNG в одинаковый квадрат.

В sprites.json приведены размеры, границы видимого содержимого, начальная
центральная привязка и результаты проверки альфа-канала. Если масштабируете
весь холст до ширины W, учитывайте долю холста, занятую растением.
Привязка (0.5, 0.5) — предварительная точка размещения, а не точное положение
ствола; при необходимости подстройте её в редакторе.

## Использование

- Кусты можно рисовать поверх земли, перед юнитами в порядке отрисовки.
- Кроны деревьев можно рисовать поверх наземной техники; при перекрытии
  своих юнитов пригодится ослабление непрозрачности кроны или контур юнита.
- Масштаб экземпляров можно слегка менять, например 0.85–1.15 от выбранного
  размера. Сильный произвольный поворот меняет также нарисованное освещение;
  сначала оцените варианты при одинаковом направлении света.
- Для отдаления камеры пригодятся mipmaps и линейная фильтрация. При упаковке
  в атлас используйте отступы, чтобы соседние спрайты не попадали в край.
- В пакет не входят отдельные тени, анимация листвы или правила проходимости.
  В репозиторий игры файлы пока не подключены.

## Проверка прозрачности

Все шесть исходников прочитаны как RGBA, содержат настоящий фон с alpha=0.
У раскидистого куста цветной ореол может быть виден в просмотрщике, который
игнорирует альфа-канал: цвет полностью прозрачных RGB-пикселей не рисуется
при корректном смешивании. Ярких красных пикселей с alpha>8/255 не обнаружено.
На краях некоторых файлов встречаются практически невидимые пиксели с
alpha=1/255. При строгой подготовке атласа их можно обнулить на этапе импорта.
PNG сохранены без ручной переработки после генерации; готовность к финальному
игровому масштабу следует оценить непосредственно на вашей карте.
