# Стратегические значки RTS — эскиз v1

15 оригинальных игровых обозначений, вдохновлённых военной картографией.
Это не набор по официальному стандарту NATO/APP-6.

Рамки: прямоугольник — наземный юнит; треугольник — авиация;
квадрат со срезанными углами и чертой основания — здание.
Одинаковые роли во всех фракциях используют одинаковые значки.
Цвет фона обозначает игрока, а не класс, фракцию или состояние.

## Файлы

- svg/: 15 готовых SVG, фон по умолчанию голубой.
- layers/team/: белые маски фона для окрашивания цветом игрока.
- layers/overlay-dark/: прозрачная рамка и тёмный знак роли.
- layers/overlay-light/: прозрачная рамка и светлый знак роли.
- png/64/ и png/128/: растровые версии тех же четырёх наборов.
- preview.png: лист всех обозначений; не игровой атлас.
- manifest.json: идентификаторы, названия и точка привязки.

## Окрашивание

В SVG меняется fill у path с id="team-fill" и color у g с id="role-mark".
В игре сначала рисуйте team-маску с tint цвета игрока, затем overlay
без tint. Для светлого/насыщенного фона берите тёмный знак,
для тёмного — светлый. Выбирайте по большему контрасту яркости.
Фон за рамкой прозрачный. Светлая рамка и тёмный внешний контур
нужны для читаемости над травой, водой и землёй.

Начальный экранный размер: 24–32 px; при 16 px детали уже теряются.
Размер указан для всей области 64×64, включая отступы.
Не вращайте значки вместе с корпусом. Направление можно показывать
отдельным индикатором только у выбранного объекта.
Выделение и здоровье лучше рисовать снаружи отдельными слоями.
Иконки не интегрированы в репозиторий игры.
